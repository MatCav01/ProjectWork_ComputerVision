# Project Work Computer Vision

Goal: MultiLabel Classification
Data: CIM Dataset (A dataset of fake banknotes)

Dataset is divided in folders based on denominations first and then on rotation.
In every folder every banknote is identified by a 4 digit number, starting with 0000.
Moreover every banknote has 2 pictures, one for the front and one for the rear. They are identified by "_front" and "_rear".
